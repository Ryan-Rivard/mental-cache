## 📏 Vault Naming & Guardrails
To keep this vault clean, consistent, and scalable, always follow these rules:
- **Filenames**: Use normal spaces and Title Case (`Internet Fundamentals.md`). Never use snake_case or slashes.
- **Acronyms**: Keep protocols in all-caps (`DNS.md`, `QUIC.md`).
- **Linking**: Apply the *First-Mention Rule*. Link a note only the very first time it appears in a file.
- **Properties**: Include a metadata header (`alias`, `tags`, `created`, `status`) on high-value study guides only.
