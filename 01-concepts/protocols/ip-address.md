# IP Address

An Internet Protocol (IP) address is a unique structural numerical identifier assigned to every device participating across a network.

---

## 🗺️ Functional Purpose
- **Device Identification**: Operates as a distinct digital mailing address for host interfaces.
- **Network Routing**: Provides the exact spatial path markers required by physical [[Router]] systems to deliver data payloads accurately.

---

## 🔢 The Structural Formats

### 1. IPv4 (Internet Protocol Version 4)
- **Size**: 32-bit numeric space.
- **Format**: Four decimal numbers separated by periods (e.g., `192.168.1.1`).
- **Limit**: Caps out at roughly 4.3 billion possible configurations, causing global address exhaustion.

### 2. IPv6 (Internet Protocol Version 6)
- **Size**: 128-bit hexadecimal numeric space.
- **Format**: Hex values split by colons (e.g., `2001:0db8:85a3:0000:0000:8a2e:0370:7334`).
- **Limit**: Provides a virtually infinite pool of unique device markers ($3.4 \times 10^{38}$).

---

## 🛡️ Types of IP Classes
- **Public IP**: Accessible globally across the internet. Assigned directly by network providers.
- **Private IP**: Hidden inside localized spaces (like your home Wi-Fi router network). Cannot route data directly on the open web without translation.
